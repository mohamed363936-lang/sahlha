# سهّلها | Sahlha — النسخة الأولية

تطبيق ويب تقدمي (PWA) بسيط لتنظيم المهام والملاحظات والمصروفات وقائمة المشتريات والحسابات. يدعم العربية والإنجليزية والفرنسية، ويحفظ البيانات محليًا في المتصفح.

## ما الذي يعمل الآن؟
- لوحة رئيسية وإحصاءات.
- إضافة المهام وتحديد تاريخها ووضع علامة الإنجاز عليها وحذفها.
- إنشاء الملاحظات وحذفها.
- تحديد ميزانية شهرية وتسجيل المصروفات وحذفها.
- قائمة مشتريات مع تحديد العناصر المنجزة.
- حاسبة للعمليات الأساسية.
- تغيير لغة الواجهة بين العربية والإنجليزية والفرنسية.
- تصدير البيانات إلى ملف JSON واستيراد نسخة احتياطية.
- ملف PWA وService Worker للتثبيت والتخزين المؤقت.
- تصميم متجاوب للكمبيوتر والهاتف.

## التشغيل على Linux

### 1. فك ضغط المشروع
فك ملف `sahlha-app.zip` إلى مجلد مثل `sahlha_app`.

### 2. افتح الطرفية داخل المجلد
في مدير الملفات، افتح المجلد، ثم انقر بزر الفأرة الأيمن واختر فتح الطرفية هنا. أو استخدم:
```bash
cd ~/Downloads/sahlha_app
```
عدّل المسار إذا وضعت المجلد في مكان آخر.

### 3. شغّل خادمًا محليًا
إذا كان Python 3 مثبتًا:
```bash
python3 -m http.server 8000
```
اترك الطرفية مفتوحة أثناء التجربة.

### 4. افتح التطبيق
افتح المتصفح على:
```text
http://localhost:8000
```
جرّب المهام والملاحظات والميزانية وتغيير اللغة. لا تفتح `index.html` مباشرة بالنقر المزدوج؛ تشغيل خادم محلي ضروري لاختبار Service Worker وميزات PWA.

### 5. اختباره على هاتفك
- الهاتف والكمبيوتر يجب أن يكونا على شبكة Wi-Fi نفسها.
- اعرف عنوان IP المحلي للكمبيوتر بالأمر:
```bash
hostname -I
```
- افتح على الهاتف `http://IP-الكمبيوتر:8000` مع استبدال النص بعنوان IP الحقيقي.
- قد يمنع جدار الحماية الوصول؛ اسمح باتصال الشبكة المحلية عند الحاجة.
- تثبيت PWA من الهاتف يتطلب عادةً HTTPS أو localhost؛ الوصول عبر عنوان IP HTTP لا يتيح التثبيت في كثير من المتصفحات.
- للنشر العام استخدم استضافة تدعم HTTPS، مثل GitHub Pages أو Cloudflare Pages أو Netlify.

## نشر نسخة عامة
يمكنك رفع ملفات المشروع إلى مستودع GitHub ثم نشره على خدمة استضافة صفحات ثابتة تدعم HTTPS. اختبر المسارات بعد النشر، لأن بعض الاستضافات تضع المشروع داخل مسار فرعي.

## الخصوصية وحدود النسخة
- البيانات محفوظة في `localStorage` على المتصفح الحالي فقط.
- حذف بيانات المتصفح قد يحذف بيانات التطبيق؛ استخدم «تصدير بياناتي» للاحتفاظ بنسخة.
- لا توجد مزامنة بين الأجهزة ولا تسجيل دخول ولا خادم في هذه النسخة.
- الإشعارات والتذكيرات ليست مفعلة في النسخة الأولى؛ تاريخ المهمة يظهر داخل التطبيق فقط.
- لا تدخل معلومات شديدة الحساسية في النسخة الأولية.
- خط Google Fonts اختياري؛ قد لا يُحمّل دون إنترنت، وسيستخدم المتصفح خطًا بديلًا.
- الحاسبة تسمح بالعمليات الأساسية فقط. لا تستخدم التطبيق لاتخاذ قرارات مالية عالية المخاطر.

## التطوير التالي
1. اختبار الواجهة مع مستخدمين وإصلاح الملاحظات.
2. إضافة تذكيرات موثوقة ومزامنة اختيارية بعد تصميم نظام الحسابات والخادم.
3. إضافة إعدادات خصوصية وتشفير للنسخ الاحتياطية إذا لزم الأمر.
4. إنشاء صفحة تعريفية وتحليلات تحترم الخصوصية.
5. اختبار إمكانية الوصول والأمان والأداء قبل الإطلاق التجاري.
